# Server SRS (scaffold)

Two deployment types with separate dependency graphs ([ADR 032](../../../../../resources/architecture/032-hosting-and-privacy-model.md)): `filesquid-server`, the owner-operated multi-user host (`SV-S` rows), and the ciphertext-only hosted service at `*.filesquid.tech` (`BE-S` rows; formerly the Axum mailbox). Parents: [SRS-F-066](../../../../../resources/srs.md#srs-f-066-file-and-folder-sharing-roles-links-and-shares-view) (SV-S-005–006), [SRS-F-057](../../../../../resources/srs.md#srs-f-057-desktop-and-server-hosts), [SRS-F-059](../../../../../resources/srs.md#srs-f-059-hosted-encrypted-backup-and-sync-service).

| Local requirement | Parent |
|---|---|
| BE-S-001 Health reports process liveness as JSON, at `/api/v1/health` through `filesquid-api` on `filesquid-server` (was `/health`) and at a health route on the hosted service. | [PRD F-037](../../../../../resources/prd.md#f-037-setup-updates-and-diagnostics) |
| BE-S-002 `/metrics` exposes Prometheus text. | [PRD NFR-009](../../../../../resources/prd.md#nfr-009-observability-and-capacity-economics), [ADR 014](../../../../../resources/architecture/014-stdout-observability.md) |
| BE-S-003 Logs are unbuffered JSON on stdout. Promtail MUST NOT be the collector. | [PRD TC-005](../../../../../resources/prd.md#tc-005-shared-rust-graph-hosted-mailbox-isolation-and-ocfl-writer), [ADR 014](../../../../../resources/architecture/014-stdout-observability.md) |
| BE-S-004 The ciphertext-only hosted service MUST NOT depend on `filesquid_ocfl`, `filesquid_metadata`, `filesquid_c2pa`, `filesquid-api` read paths over private plaintext, any other module that processes private plaintext, libvips or FFmpeg, MUST NOT parse OCFL and MUST NOT hold library keys. CI MUST fail when any of these enters its dependency graph; Cargo features MUST NOT be the only boundary. (Re-scoped from the whole crate to the hosted service.) | [PRD TC-005](../../../../../resources/prd.md#tc-005-shared-rust-graph-hosted-mailbox-isolation-and-ocfl-writer), [PRD F-059](../../../../../resources/prd.md#f-059-hosted-encrypted-backup-and-sync-service) |
| SV-S-001 `filesquid-server` MUST support multiple users and groups, personal and group-owned libraries, and collection-level permissions, checked on every API call. Group membership MUST NOT grant ownership of personal libraries. | [F-057](../../../../../resources/prd.md#f-057-desktop-and-server-hosts), [FileSquid U-06](../../../../../resources/product-vision.md#platform-ownership-and-access), [T-053](../../../../../resources/product-vision.md#api-and-hosts) |
| SV-S-002 `filesquid-server` MUST serve the FileSquid API and the selected distribution's static UI (`FILESQUID_UI_DIR`) from one process, and MUST NOT server-render private pages. | [F-057](../../../../../resources/prd.md#f-057-desktop-and-server-hosts), [FileSquid U-19](../../../../../resources/product-vision.md#one-api-hosts-and-distributions), [ADR 030](../../../../../resources/architecture/030-filesquid-api-and-transports.md) |
| SV-S-003 The server's canonical file state MUST be an OCFL storage root on local or S3-compatible storage; PostgreSQL holds operational data only and the root MUST be rebuildable into a working server without it. | [F-042](../../../../../resources/prd.md#f-042-ocfl-preservation-and-portable-recovery), [FileSquid U-03](../../../../../resources/product-vision.md#platform-ownership-and-access), [ADR 005](../../../../../resources/architecture/005-sqlite-local-postgres-hosted.md) |
| SV-S-004 The UI served by `filesquid-server` MUST state that the server's operator can read the files it stores. | [F-057](../../../../../resources/prd.md#f-057-desktop-and-server-hosts), [SRS-F-057](../../../../../resources/srs.md#srs-f-057-desktop-and-server-hosts), [FileSquid U-20](../../../../../resources/product-vision.md#one-api-hosts-and-distributions), [ADR 032](../../../../../resources/architecture/032-hosting-and-privacy-model.md) |
| SV-S-005 `filesquid-server` MUST store shares (file, logical-path prefix or collection; user, group, team or public link; role viewer, commenter or editor, none of which grants library deletion; re-share flag; link password hash and expiry) and evaluate them deny-by-default with collection permissions on every API call; public-link downloads MUST be journaled and apply the outgoing metadata policy; ownership transfer MUST be offer-and-accept with a pending state. | [F-066](../../../../../resources/prd.md#f-066-file-and-folder-sharing-roles-links-and-shares-view), [SRS-F-066](../../../../../resources/srs.md#srs-f-066-file-and-folder-sharing-roles-links-and-shares-view) |
| SV-S-006 Sharing itself (new shares), public links, re-sharing and download MUST each be switchable per server by an administrator; every switch MUST be journaled and reported to the UI so it can hide the control and attribute the restriction. Billing administration MUST grant no share or read access. | [F-057](../../../../../resources/prd.md#f-057-desktop-and-server-hosts), [F-066](../../../../../resources/prd.md#f-066-file-and-folder-sharing-roles-links-and-shares-view), [SRS-F-057](../../../../../resources/srs.md#srs-f-057-desktop-and-server-hosts) |
| SV-S-007 `filesquid-server` MUST NOT offer operator-key encryption at rest and MUST NOT hold an administrator recovery key for users' content. At-rest protection of its storage is the operator's disk or bucket encryption outside FileSquid; the SV-S-004 boundary statement MUST say so. | [F-057](../../../../../resources/prd.md#f-057-desktop-and-server-hosts), [SRS-F-057](../../../../../resources/srs.md#srs-f-057-desktop-and-server-hosts), [F-035](../../../../../resources/prd.md#f-035-optional-service-extensions) |
