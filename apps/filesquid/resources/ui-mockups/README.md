# FileSquid UI mockups

Wireframes, mockups, flows, and look-and-feel examples for surfaces owned by `apps/filesquid`. They feed this app's `resources/srs.md`. **Active suite:** none yet. When you add one, name it here. Only the active suite named in this README is a requirement source.
